TRACK 1 RESULT: SEQC2 HCC1395 SOMATIC SNV/INDEL VALIDATION
================================================================

Headline exact-allele benchmark

Type   TP   FP   FN   Precision   Recall   F1
SNV   705  283  700     0.7136   0.5018  0.5892
INDEL  32   16   19     0.6667   0.6275  0.6465

These figures compare normalized PASS Mutect2 calls with normalized SEQC2
v1.2.1 high-confidence truth alleles using bcftools isec. No matching tolerance
or post-hoc caller tuning was used.

Go/no-go truth-count gate

The cBioPortal IMPACT468 list produced 44 truth SNVs and 1 truth indel in
high-confidence panel exons (45 combined), below the preregistered minimum of
200. Calling therefore did not proceed on that small panel alone. The region
was widened to all GENCODE v50 basic protein-coding exons intersected with the
SEQC2 high-confidence BED. The final region contains 225,074 merged intervals,
96,549,992 bp, 1,405 truth SNVs, and 51 truth indels (1,456 combined).

Data and build verification

- Tumor: NCBI SEQC2 WES_LL_T_1, read-group sample WES_LL_T_1 (HCC1395).
- Normal: NCBI SEQC2 WES_LL_N_1, read-group sample WES_LL_N_1 (HCC1395BL).
- Both remote BAM headers name GRCh38.d1.vd1.fa and use chr-prefixed GRCh38
  primary contigs. Remote indexed HTTPS random access was tested before use.
- Reference: official GDC GRCh38.d1.vd1 archive; archive MD5 verified as
  3ffbcfe2d05d43206f57f81ebb251dc9.
- Truth: NCBI SEQC2 v1.2.1 SNV/indel calls plus v1.2 high-confidence regions.
- Annotation: official current GENCODE human release 50, GRCh38.p14.
- Gene panel: cBioPortal IMPACT468 API. Its description says 468 genes, but the
  current endpoint returns 469 unique symbols and includes GTF2I. The source
  list was preserved and the discrepancy was recorded.

Read subsetting

No full WES BAM was downloaded. samtools streamed only reads overlapping the
final exons plus 200 bp assembly padding from the indexed NCBI BAMs. The local
tumor slice contains 41,965,481 alignments and is 2,041,679,847 bytes; the
normal slice contains 56,402,632 alignments and is 2,715,330,153 bytes.

Calling

GATK 4.6.2.0 Mutect2 was run in matched tumor-normal mode, followed by
FilterMutectCalls. PASS calls were restricted to the exact unpadded validation
BED and normalized against GRCh38.d1.vd1 before comparison. The final callset
contains 988 SNVs and 48 indels.

Laptop feasibility

The completed final run used four or fewer CPU cores. Remote slicing took
2m33s and peaked at 32.0 MiB RSS. Mutect2 took 1h51m and peaked at
1,019.3 MiB RSS. Filtering took 11.4s and peaked at 657.3 MiB; benchmarking
took 1.7s and peaked at 26.2 MiB. Final-run work directories occupy about
8.3 GiB; the Conda environment/cache occupies 5.4 GiB. The broader abandoned
trial remains in Nextflow work, bringing the current work directory to 13 GiB
and total project use to roughly 18.4 GiB, still below the 50 GB limit.

Interpretation and limitations

This is a caller-validation demonstration, not an AML-specific performance
estimate: HCC1395 is a breast-cancer reference cell line. Recall reflects one
SEQC2 WES replicate and its coverage, while truth was constructed using richer
multi-platform evidence. Mutect2 was deliberately run as a simple matched-pair
workflow without a panel of normals, gnomAD germline prior, contamination
estimation, or orientation-bias filtering. Those omissions keep the demo open
and reproducible but likely reduce precision. The exact-match benchmark also
counts representation-discordant complex alleles as errors after standard
left-normalization; no fuzzy matching was introduced.
